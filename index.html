Questions

Clear expectations before checkout.

Is this a new operating system that replaces Windows?

No. It is an application and workflow layer that runs on top of your existing computer.

Do I need to be a senior developer?

No, but you should be comfortable installing software, opening VS Code, running terminal commands, and reviewing explanations.

Does the guide include Ars Goetia?

No. Ars Goetia is the private case study. Buyers receive separate sanitized teaching code.

No. The guide teaches a software-building workflow. It does not guarantee income, customers, or business results.

No. Vendor accounts, subscriptions, API access, and usage charges are separate.
